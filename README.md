# 3d-1st-game

Title Project "jump"


Genre

    3D Platformer / Adventure

Core Idea

    The player must navigate through a short obstacle course of platforms, moving objects, and hazards to reach the end goal as quickly as possible.

Mechanics
    Basic movement (WASD + jump)
    Moving platforms (left/right, up/down)
    Obstacles (gaps, falling areas)
    Simple physics (gravity, jumping timing)
    Respawn system when player falls
Win Condition
    Reach the end zone (goal area/arch)
Lose Condition
    Fall off the map or into a hazard → respawn
UI Plan
    Start screen (Play button)
    In-game minimal UI (optional timer)
    Win screen (You Win + Restart button)
L   ose/Respawn screen (Respawn button)
